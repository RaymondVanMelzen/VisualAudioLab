# Visual Audio Lab Roadmap

*Last updated: November 2026*

## Vision

Visual Audio Lab (VAL) is not intended to be "just another synthesizer" or effects processor.

The goal is to create a visual environment in which users can:

- Learn how audio and DSP work
- Experiment safely with signal chains
- Build and test audio processing modules
- Visualize signal flow and signal behavior
- Prototype synthesis and effects algorithms
- Understand the relationship between mathematics, sound and perception

The roadmap therefore prioritizes usability, insight, and experimentation over the sheer number of available modules.

# Guiding Principles

Every feature should improve at least one of the following:

- Learnability
- Discoverability
- Reliability
- Reusability
- Insight into signal behavior

Features that increase complexity without improving these goals should be reconsidered.

---

# Roadmap Philosophy

Visual Audio Lab is not measured by the number of modules it contains.

It is measured by how effectively it helps users understand, explore and create with sound.
