# Retired VAL Script design archive

These files preserve the original VAL Script language specification and
architecture proposal for historical reference. They are not active product
requirements or supported application documentation.

- `ValScript.md` — the former implemented language/runtime and editor contract.
- `ValScriptArchitecture.md` — the former language and compiler design.

The corresponding compiler, runtime, editor, catalog entry and examples have
been removed. Legacy project compatibility and migration guidance are in
[`../../ValScriptRetirementPlan.md`](../../ValScriptRetirementPlan.md).
