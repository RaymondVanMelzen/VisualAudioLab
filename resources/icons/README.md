# Visual Audio Lab application icon

These are the nine original user-provided artwork files, kept byte-for-byte in
this directory. The supplied ICO files each contain 16, 24, 32, 48, 64, 72,
96, 128 and 256 pixel frames. Windows builds embed the supplied 256-pixel ICO
as a native executable icon resource. The 256-pixel PNG is embedded for the
JUCE window/taskbar icon. The remaining PNG and ICO originals are retained as
provided and are not rewritten during the build.

| File | Use |
|---|---|
| `VAL_16x16.ico` | Windows small application icon source |
| `VAL_32x32.ico` | Original supplied icon |
| `VAL_64x64.ico` | Original supplied icon |
| `VAL_256x256.ico` | Windows large application icon source |
| `VAL_16x16.png` | Original supplied image |
| `VAL_32x32.png` | Original supplied image |
| `VAL_64x64.png` | Original supplied image |
| `VAL_256x256.png` | Embedded JUCE window/taskbar icon |
| `VAL_533x533.png` | Original supplied image |
